# פסגת ליאם — מערכת חתימה דיגיטלית (pisgat-liam-sign)

לקוח מקבל **לינק אחד**, פותח בטלפון, מעיין במסמכים, ממלא את השדות הריקים,
מצייר חתימה אחת באצבע — והמערכת מטביעה אותה בכל נקודות החתימה בכל המסמכים,
מוסיפה **נספח תיעוד חתימה אלקטרונית** (מועד, IP, מכשיר, SHA-256, הצהרת הסכמה)
ושולחת את הקבצים החתומים + audit JSON **לטלגרם של דקל**. החותם מקבל עותקים להורדה.

## ארכיטקטורה
- Flask + pypdf + reportlab. שום דבר לא נשמר בשרת — **טלגרם הוא הארכיון**.
- חבילת חתימה = תיקייה `packages/<token>/` עם `package.json` (שדות + קואורדינטות)
  וקובצי ה-PDF המקוריים. הטוקן הוא ה-URL: `/s/<token>` — ארוך ובלתי ניתן לניחוש.
- הריפו **פרטי** (מכיל חוזי לקוחות). האתר הציבורי נשאר בריפו נפרד.

## הוספת לקוח חדש
1. מכינים את ה-PDF-ים (כמו סט סלהוב — נוצרים מתבנית ה-DOCX).
2. מריצים כלי בניה בסגנון `tools/build_salhov_package.py` — הוא מאתר את קווי
   החתימה והשדות הריקים אוטומטית (pdfplumber; עברית מחולצת בסדר ויזואלי —
   העוגנים מוגדרים הפוך) וכותב `package.json`.
3. קומיט + פוש → Render פורס אוטומטית → שולחים ללקוח `https://<service>/s/<token>`.

## משתני סביבה (Render)
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — אותו בוט תפעול של דקל.

## הרצה מקומית
```
pip install -r requirements.txt
python app.py   # http://127.0.0.1:5511/s/<token>
```
בלי משתני טלגרם המערכת עובדת אבל לא שולחת (delivered=false) — טוב לבדיקות.

## מגבלות ידועות (v1)
- אין OTP למייל — הזיהוי נשען על מסירת הלינק לנמען ידוע + תיעוד IP/מכשיר/זמן.
- Free tier ב-Render נרדם באי-פעילות — קליק ראשון עשוי לקחת ~30-60 שניות.
